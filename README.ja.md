<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/ecommerce-sales-analysis/raw/main/assets/icons/ecommerceSales.png" width="40"/> ECサイト売上分析</h1>

<p align="center">
  このプロジェクトでは、売上データを分析し、重要なビジネスインサイトを発見するとともに、顧客や商品のパフォーマンスを分析し、売上傾向を可視化することで、データに基づいた意思決定を支援します。
</p>

## <img src="https://github.com/KrishBharadwaj5678/ecommerce-sales-analysis/raw/main/assets/readme/features.gif" width="35"/> 機能

| 機能 | 説明 |
| ---- | ---- |
| 📊 売上データ分析 | ECサイトの売上データを分析し、重要なビジネスインサイトを発見 |
| 💰 売上・収益分析 | 収益、売上パフォーマンス、ビジネス全体の成長を分析 |
| 🛍️ 商品パフォーマンス | 売上上位の商品と売上が低い商品を特定 |
| 👥 顧客分析 | 顧客の購買パターンや行動を分析 |
| 📈 売上トレンド分析 | 異なる期間における売上の傾向を分析 |
| 🌍 地域別分析 | 地域やエリアごとの売上パフォーマンスを比較 |
| 📅 時系列分析 | 月次、四半期、年次の売上パターンを分析 |
| 📉 データ可視化 | 分かりやすいグラフやチャートを使用して分析結果を表示 |
| 🔍 ビジネスインサイト | データから傾向やパターンを発見し、意思決定を支援 |
| 🧹 データクリーニング | 生の売上データを整理・加工し、正確な分析に使用できる状態にする |

## <img src="https://github.com/KrishBharadwaj5678/ecommerce-sales-analysis/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/ecommerce-sales-analysis.git
```

### 2️⃣ プロジェクトフォルダへ移動

```bash
cd ecommerce-sales-analysis
```

### 3️⃣ 必要なライブラリをインストール

```bash
pip install -r requirements.txt
```

### 4️⃣ Jupyter Notebookを起動

```bash
jupyter notebook
```

### 5️⃣ 分析ノートブックを開く

Jupyter Notebookで `.ipynb` ファイルを開き、セルを順番に実行してください。
