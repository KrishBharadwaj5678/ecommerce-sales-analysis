<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/ecommerce-sales-analysis/raw/main/assets/icons/ecommerceSales.png" width="40"/> Ecommerce Sales Analysis</h1>

<p align="center">

</p>

## <img src="https://github.com/KrishBharadwaj5678/ecommerce-sales-analysis/raw/main/assets/readme/features.gif" width="35"/> Features

| Feature                  | Description                                                               |
| ------------------------ | ------------------------------------------------------------------------- |
| 📊 Sales Data Analysis   | Analyze e-commerce sales data to uncover important business insights      |
| 💰 Revenue Analysis      | Track revenue, sales performance, and overall business growth             |
| 🛍️ Product Performance  | Identify top-selling and low-performing products                           |
| 👥 Customer Analysis     | Understand customer purchasing patterns and behavior                      |
| 📈 Sales Trend Analysis  | Analyze sales trends across different time periods                        |
| 🌍 Regional Analysis     | Compare sales performance across different regions and locations          |
| 📅 Time-Based Insights   | Examine monthly, quarterly, and yearly sales patterns                     |
| 📉 Data Visualization    | Present insights using clear and meaningful charts and graphs             |
| 🔍 Business Insights     | Discover patterns and trends to support data-driven decisions             |
| 🧹 Data Cleaning         | Clean and prepare raw sales data for accurate analysis                    |

## <img src="https://github.com/KrishBharadwaj5678/ecommerce-sales-analysis/raw/main/assets/readme/gettingStarted.gif" width="35"/> Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/KrishBharadwaj5678/ecommerce-sales-analysis.git
```

### 2️⃣ Navigate to the Project

```bash
cd ecommerce-sales-analysis
```

### 3️⃣ Install Required Libraries

```bash
pip install -r requirements.txt
```

### 4️⃣ Launch Jupyter Notebook

```bash
jupyter notebook
```

### 5️⃣ Open the Analysis Notebook

Open the .ipynb file in Jupyter Notebook and run the cells sequentially.
