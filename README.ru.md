<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/ecommerce-sales-analysis/raw/main/assets/icons/ecommerceSales.png" width="40"/> Анализ продаж в электронной коммерции</h1>

<p align="center">
  Этот проект посвящён исследованию данных о продажах, выявлению ключевых бизнес-инсайтов, анализу эффективности клиентов и товаров, а также визуализации тенденций продаж для поддержки принятия решений на основе данных.
</p>

## <img src="https://github.com/KrishBharadwaj5678/ecommerce-sales-analysis/raw/main/assets/readme/features.gif" width="35"/> Возможности

| Возможность | Описание |
| ----------- | -------- |
| 📊 Анализ данных о продажах | Анализ данных о продажах для выявления важных бизнес-инсайтов |
| 💰 Анализ выручки | Отслеживание выручки, эффективности продаж и общего роста бизнеса |
| 🛍️ Эффективность товаров | Определение наиболее и наименее продаваемых товаров |
| 👥 Анализ клиентов | Изучение покупательского поведения и моделей покупок клиентов |
| 📈 Анализ тенденций продаж | Анализ динамики продаж за различные периоды времени |
| 🌍 Региональный анализ | Сравнение эффективности продаж в разных регионах и локациях |
| 📅 Анализ по времени | Исследование месячных, квартальных и годовых показателей продаж |
| 📉 Визуализация данных | Представление результатов с помощью понятных графиков и диаграмм |
| 🔍 Бизнес-инсайты | Выявление закономерностей и тенденций для принятия решений на основе данных |
| 🧹 Очистка данных | Очистка и подготовка исходных данных о продажах для точного анализа |

## <img src="https://github.com/KrishBharadwaj5678/ecommerce-sales-analysis/raw/main/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/ecommerce-sales-analysis.git
```

### 2️⃣ Переход в папку проекта

```bash
cd ecommerce-sales-analysis
```

### 3️⃣ Установка необходимых библиотек

```bash
pip install -r requirements.txt
```

### 4️⃣ Запуск Jupyter Notebook

```bash
jupyter notebook
```

### 5️⃣ Открытие ноутбука с анализом

Откройте файл `.ipynb` в Jupyter Notebook и последовательно выполните ячейки.
