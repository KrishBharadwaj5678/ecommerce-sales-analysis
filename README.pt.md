<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/ecommerce-sales-analysis/raw/main/assets/icons/ecommerceSales.png" width="40"/> Análise de Vendas de E-commerce</h1>

<p align="center">
  Este projeto tem como objetivo explorar dados de vendas, identificar insights importantes para o negócio, analisar o desempenho de clientes e produtos e visualizar tendências de vendas para apoiar a tomada de decisões baseada em dados.
</p>

## <img src="https://github.com/KrishBharadwaj5678/ecommerce-sales-analysis/raw/main/assets/readme/features.gif" width="35"/> Funcionalidades

| Funcionalidade | Descrição |
| -------------- | --------- |
| 📊 Análise de Dados de Vendas | Analisa dados de vendas de e-commerce para descobrir insights importantes para o negócio |
| 💰 Análise de Receita | Acompanha a receita, o desempenho das vendas e o crescimento geral do negócio |
| 🛍️ Desempenho de Produtos | Identifica os produtos com melhor e pior desempenho em vendas |
| 👥 Análise de Clientes | Compreende os padrões de compra e o comportamento dos clientes |
| 📈 Análise de Tendências de Vendas | Analisa as tendências de vendas em diferentes períodos |
| 🌍 Análise Regional | Compara o desempenho das vendas entre diferentes regiões e localidades |
| 📅 Análise Temporal | Examina os padrões de vendas mensais, trimestrais e anuais |
| 📉 Visualização de Dados | Apresenta os resultados por meio de gráficos e visualizações claras |
| 🔍 Insights de Negócio | Descobre padrões e tendências para apoiar decisões baseadas em dados |
| 🧹 Limpeza de Dados | Limpa e prepara os dados brutos de vendas para uma análise precisa |

## <img src="https://github.com/KrishBharadwaj5678/ecommerce-sales-analysis/raw/main/assets/readme/gettingStarted.gif" width="35"/> Como Começar

### 1️⃣ Clonar o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/ecommerce-sales-analysis.git
```

### 2️⃣ Acessar a Pasta do Projeto

```bash
cd ecommerce-sales-analysis
```

### 3️⃣ Instalar as Bibliotecas Necessárias

```bash
pip install -r requirements.txt
```

### 4️⃣ Iniciar o Jupyter Notebook

```bash
jupyter notebook
```

### 5️⃣ Abrir o Notebook de Análise

Abra o arquivo `.ipynb` no Jupyter Notebook e execute as células sequencialmente.
